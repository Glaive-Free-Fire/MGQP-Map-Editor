# MGQP Map Editor v1.5.34

**Современный веб-инструмент для редактирования и пакетного исправления файлов карт и событий RPG Maker XP с расширенной поддержкой процессов локализации (RU/JP), валидацией логической структуры и массовым исправлением ошибок.**

---

## Основные возможности

- **Визуальный редактор блоков:** Удобное блочное редактирование команд `ShowText`, `ShowTextAttributes`, `ShowChoices`, `When`, `JumpToLabel`, `Label`, `Script`, `ScriptMore` и других.
- **Поддержка перевода (RU / JP):** Загрузка русской и оригинальной японской версии для параллельного сопоставления строк и контекстного перевода.
- **Режим создания перевода с нуля (Japanese-Only):** Возможность загрузить только японский файл — редактор автоматически создаст структурированные заготовки для перевода.
- **Валидация логического скелета (Красная / Зелёная лампа):** Автоматическая проверка целостности структуры (переключатели, переменные, ветвления). Текстовые команды `ShowText` и `ShowTextAttributes` не вызывают ложных срабатываний лампы, что позволяет свободно делить и форматировать реплики.
- **Связывание имён персонажей (Linked Character Names):** Модальное окно для группировки синонимичных вариантов написания имён (например, `【玉藻】` и `【たまも】`). Автозамена дубликатов и сопоставление распознают связанные имена как одного персонажа. Настройки сохраняются в `localStorage`.
- **Быстрая навигация между картами:** Плавающая панель с кнопками перехода к предыдущей/следующей карте (`↩` / `↪`) и счётчиком текущего файла (`X/Y`), избавляющая от необходимости постоянно выбирать файлы вручную.
- **Режим «Показать все Script»:** Чекбокс `showAllScriptsCheckbox` позволяет отобразить все технические скриптовые команды `Script` и `ScriptMore`, включая команды без японского текста.
- **Пакетная обработка папок (Batch Processing):** Массовая проверка и автоисправление целых папок с картами с последующим экспортом исправленных файлов в ZIP-архив.
- **Детализация ошибок в пакетном режиме:** Поддержка сниппетов оригинального японского кода при структурных сбоях и опция вывода несопоставленных файлов в начале списка.
- **Умное разделение диалогов (Hot Reload):** Автоматическое разбиение длинных строк с последующим мгновенным перепарсингом и расстановкой нужных тегов и разделителей `ShowTextAttributes #+`.
- **Система чанков для больших файлов:** Файлы объёмом более 5000 строк автоматически нарезаются на части для стабильной работы браузера без потери синхронизации.
- **Автосохранение и восстановление сессий:** Фоновое резервное копирование в `localStorage` каждые 5 минут с предложением восстановления при случайном закрытии страницы или сбое.
- **Метка игнорирования японского текста (`##`):** Возможность указать маркер `##` в конце строки `ShowText`, чтобы исключить её из детекции непереведённого японского текста (поддерживается и на сгенерированных `#+` строках).
- **Надёжная очистка и фильтрация:** Автоудаление пустых строк `ShowText`, защита от зацикленных тильд (`∾{3,}`) и повреждённых сбросов цвета (`∾C[0]` / `∾∾∾C[0]`), бережная очистка ненужных `ShowTextAttributes`.

## История изменений

## Changelog (v1.5.34)

### Модуль связывания имён персонажей
*   **Связывание псевдонимов и вариантов:** Добавлено модальное окно для объединения различных написаний имён (например, кандзи и хирагана: `【玉藻】` ↔ `【たまも】`).
*   **Единое распознавание дубликатов:** Детектор дубликатов считает связанные имена единым персонажем, устраняя ложные предупреждения и позволяя синхронизировать реплики в один клик.
*   **Постоянное хранение:** Группы имён сохраняются в `localStorage` браузера (`mgqp_linked_names`) и сохраняются между сессиями.

### Навигация и интерфейс
*   **Быстрая навигация:** Плавающий виджет (`↩` / `↪`) позволяет переключаться между картами проекта без вызова диалога выбора файлов.
*   **Показать все Script:** Добавлен чекбокс `showAllScriptsCheckbox` для отображения всех скриптовых команд (включая чисто технические без японских символов).
*   **Естественная сортировка файлов:** Файлы сортируются с учётом чисел в названии (например, `Map002` перед `Map010`).

### Пакетная обработка (Batch Processing)
*   **Несопоставленные файлы в начале:** Добавлен чекбокс «Выводить строки без сопоставления в начале списка» (`batchShowUnmatchedFirst`).
*   **Сниппеты японского оригинала:** При структурных расхождениях в отчёте теперь отображается фрагмент исходного японского кода для наглядности.
*   **Очистка заголовков событий:** Корректное отображение `CommonEvent` без названия.

### Стабильность и оптимизация движка
*   **Автоочистка пустых ShowText:** Полностью пустые строки `ShowText` автоматически удаляются при генерации и сохранении.
*   **Защита от повреждённых тегов:** Добавлена проверка на избыток тильд (`∾{3,}`) и некорректные сбросы цвета (`∾C[0]` / `∾∾∾C[0]`).
*   **Безопасная расстановка тегов имён:** Функции `fixLongDialogues` и `autoFixNameTagErrors` очищают старый мусорный префикс перед добавлением нового тега имени.
*   **Защита разрывов предложений:** В `restore-mode.js` разделители `ShowTextAttributes #+` сохраняются, если перед ними уже есть 4+ строки диалога, предотвращая удаление вынужденных разрывов.
*   **Удаление отладочных файлов:** Удалены устаревшие тестовые скрипты (`debug_batch_mode.js`, `debug_full_test.html`).

## Changelog (v1.5.15)

### 1. Обработка больших файлов (Система чанков)
*   **Чередование частей**: Файлы, превышающие 5000 строк, автоматически разбиваются на «чанки» (части). Это позволяет избежать зависаний браузера при отрисовке огромного количества элементов в DOM.
*   **Синхронизация границ**: Японский оригинал нарезается строго по тем же границам `CommonEvent`, что и русский перевод, что исключает рассинхронизацию строк в конце каждой части.
*   **Навигация**: Добавлены кнопки «Пред. Часть» и «След. Часть» с индикатором текущего положения (например, «Часть 1/3»).
*   **Корректное сохранение**: При нажатии «Сохранить» редактор автоматически склеивает все части в один целый файл.

### 2. Защита данных и Автосохранение
*   **Кэширование сессии (localStorage)**: Фоновое автосохранение каждые 5 минут. При случайном закрытии вкладки или сбое сессия легко восстанавливается.
*   **Защита от перезаписи**: При загрузке нового файла кэш полностью сбрасывается.

### 3. Улучшенная детекция ошибок и валидация
*   **Слипание структурных строк**: Проверка на отсутствие пустой строки перед блоками `CommonEvent` и `Page` с автоматическим исправлением при сохранении.
*   **Детекция незакрытых кавычек**: Проверка на нечётное количество кавычек `"` внутри блоков `ShowText`.
*   **Display Name**: Заголовок `Display Name` добавляется только в самый первый чанк файла.

### 4. Оптимизация интерфейса
*   **Удален «Режим переноса»**: Убрана кнопка `wrapModeBtn` и связанная с ней логика.
*   **Удалена кнопка "\...\" (wrapSlashesBtn)**: Вырезана логика отслеживания фокуса и функции автоматической расстановки слешей для снижения нагрузки на CPU.
*   **Удалены кнопки Undo/Redo**: Устаревшие кнопки «↺» и «↻» удалены из интерфейса для чистоты кода.

### 5. Исправление багов
*   **Чистка кода в test_mode.js**: Из цикла поиска ID предметов удалён ошибочно вставленный дублирующий блок кода.
*   **Сброс состояния**: При загрузке новой карты сбрасываются старые ошибки, имя карты и флаги изменений.
